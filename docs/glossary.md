# Glossary

Terms picked for the Russian translation, so the same thing is called the same thing everywhere.
The English column is the key in the code; the Russian column is what a reader sees.

| English | Russian | Why |
|---|---|---|
| capture (noun) | снимок | A screenshot that Shotput took. «Скриншот» is slang; «снимок» matches macOS. |
| to capture | снять | «Снять область», «Снять окно». |
| area | область | The dragged rectangle. |
| preview | превью | Unchanged: it is the floating panel, and «предпросмотр» is long. |
| annotate | разметить, разметка | Not «аннотировать»: the app's own voice is plain. |
| pin (noun) | закреплённый снимок | The pinned screenshot in the menu bar. «Булавка» only in prose about the button. |
| to pin | закрепить | |
| pin shelf | полка закреплённых | The strip of pins. |
| clipboard | буфер обмена | macOS term. |
| shortcut / hotkey | сочетание клавиш | «Горячие клавиши» is common but less precise; the tab is «Сочетания». |
| Screen Recording | Запись экрана | The macOS privacy setting, named as in System Settings. |
| Screen & System Audio Recording | Запись экрана и системного звука | Same, for macOS 15 and later. |
| Keyboard Shortcuts (settings pane) | Сочетания клавиш | macOS pane name. |
| Screenshots (section in that pane) | Снимки экрана | macOS section name. |
| step number | номер шага | The counter tool. |
| redact | закрасить | Not «редактировать»: it hides content. |
| highlighter | маркер | |
| pen | перо | |
| padding | отступы | Around a window capture. |
| template | шаблон | Filename template. |
| tokens (filename tokens) | подстановки | «Токены» is programmer jargon in an end-user field. |
| colour | цвет | The app is British English; Russian needs no distinction. |
| the folder | папка | Fallback in a sentence when no save folder is picked. |

House style:

- Short sentences. The English uses full stops where a comma would do, and the Russian keeps that.
- No em dashes: a colon, a comma, or a full stop carries the same weight.
- Instructions address the reader as «вы», with the verb in the imperative («Выберите папку»).
- Proper names stay Latin: Shotput, macOS, Retina, Logi Options+, Spotlight, Dock.
- Keyboard glyphs stay as glyphs: ⇧⌘3, ⌥-click becomes «⌥+щелчок».
- Quotation marks are «ёлочки», inner quotes are „лапки“.
